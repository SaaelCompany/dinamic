# Portal Dynamic Fields — дополнительные поля на портале Jira Service Management

Плагин для Jira Server/Data Center 8.21 и Jira Service Management 4.21.
Поля, варианты ответов и условия показа задаются **в самом плагине**. Пользовательские поля Jira создавать не нужно: на портале рисуется свой блок, а ответы сохраняются в заявке и видны сотруднику поддержки.

```
[x] Медицинский сотрудник
      ├─ [x] Основная специальность
      │        ├─ Профиль                 (список)
      │        ├─ Стаж                    (текст)
      │        └─ [x] Есть сертификаты
      │                 └─ Перечень сертификатов
      └─ [ ] Дополнительная специальность
               └─ Дополнительный профиль  (список)
```

Вложенность не ограничена. Поле может зависеть только от поля, которое стоит выше, поэтому цикл невозможен. Скрытие ветки очищает её ответы, и в заявку они не попадают.

## Сборка

Нужны **JDK 8** и **Maven 3.6+**. Atlassian SDK не обязателен.

```bash
mvn clean package
# target/portal-dynamic-fields-2.1.0.jar
```

На JDK 11/17/21 профиль `jdk9-plus` включает `--release 8`, байткод остаётся версии 52, и Jira 8.21 его загружает:

```bash
unzip -p target/portal-dynamic-fields-2.1.0.jar ru/saael/dynamicfields/rest/RulesResource.class | head -c 8 | xxd
# ... 0000 0034  -> major version 52 = Java 8
```

Локальная Jira с плагином (скачивает Jira 8.21.1 и JSM 4.21.1):

```bash
mvn jira:run
# http://localhost:2990/jira  admin / admin
```

Пока `jira:run` запущен, обновляйте плагин командой `mvn package` **без** `clean`: QuickReload подхватит jar. `clean` удалит `target/jira` вместе с работающей Jira.

## Установка

1. Администрирование → Приложения → Загрузить приложение → `portal-dynamic-fields-2.1.0.jar`.
2. Приложения → **Динамические поля → Динамические поля портала** (или `/plugins/servlet/dynamic-fields/admin`).
3. «Добавить блок» или «Вставить пример». Поля стоят деревом: вложенное поле — сразу под тем, от которого зависит. Справа предпросмотр.
4. «Сохранить». Обновите страницу портала, где создаётся запрос: блок появляется над кнопкой отправки сам, отдельным полем Jira его добавлять не нужно.
5. Несколько блоков — кнопка «Добавить блок». У каждого свой заголовок, свои поля и свой список типов запросов. Пустой список — блок на всех формах создания. Иначе укажите число после `/create/` в адресе портала.

Если после обновления страница выглядит пустой, установите jar **2.1.0** и обновите страницу с очисткой кэша (Ctrl+F5). Старые правила, которые прятали пользовательские поля Jira, больше не используются. Сохранённая форма версии 2.0 открывается как один блок.

## Что видит поддержка

Ответы пишутся в заявку плагином, а не в поля Jira. На экране заявки слева появляется блок **«Ответы с портала»**. Тот же блок виден автору на странице созданного запроса.

Записать ответы может автор заявки в течение 30 минут после создания, а также пользователь с правом редактировать задачу или администратор Jira. Читать их может тот, кто видит заявку.
